# Инфографики

Самостоятельные интерактивные HTML-инфографики для уроков — каждая работает
как один файл, открывается прямо в браузере, без сборки и без сервера.

Дизайн общий для всех — палитра и фон в `_template.html` (взяты из
дизайн-системы `edu-modules`, шаблон интерактивов «Компьютерная грамотность»).

## Список

- [Как компьютер видит буквы](Как%20компьютер%20видит%20буквы/symbols-demo.html) — ввод символа → его код в Unicode → биты в памяти → пиксельная матрица на экране.
